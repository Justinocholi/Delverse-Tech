## ✦ System Architecture & Design System

The platform is built on an enterprise dark aesthetic adhering to strict mathematical typography and glassmorphic surface tokens:

* **Color Palette:**
  * Base Background: `#0A0A0B` (Near-Black)
  * Secondary Surface: `#111113`
  * Card Surfaces: `#151518` with subtle 1px glass borders (`rgba(255, 255, 255, 0.08)`)
  * Primary Typography: Pure White (`#FFFFFF`)
  * Secondary Typography: Muted Gray (`#9CA3AF`)
  * Accent Highlight: Electric Blue (`#0066FF`) & Cyan (`#38BDF8`)
* **Signature 3D Artwork (`CinematicArtwork.tsx`):**
  * Procedural vector shaders rendering flowing liquid-metal ribbons, fluid-glass refractions, and circuit-board micro-textures.
  * 12 distinct section variants (zero stock photos, zero flat illustrations).
* **Integral 4K Systems Reel Video Player (`/video.mp4`):**
  * Ambient background layer in the Hero with dark obsidian gradient overlay and telemetry controls.
  * Dedicated interactive systems reel frame in Section 4 (*Intelligence Meets Engineering*).
  * Expandable high-definition video modal.

## ✦ Development & Deployment

### Run Locally:
```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev
# -> Local server available at http://localhost:3000/
```

### Production Build:
```bash
# Compile TypeScript and bundle with Vite
npm run build
```
